## Features

- Warm amber palette, easy on the eyes
- Serif typography for an immersive reading experience
- Smooth, subtle animations

## Installation

1. Download `manifest.json` and `theme.css`
2. Copy both files to `<vault>/.obsidian/themes/Amber/`
3. Go to Settings → Appearance → Themes and enable "Amber"
