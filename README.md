# Claude Theme Like

一款优雅、沉稳、专注的浏览器主题，灵感来自 Claude 网页界面的字体排印与美学风格，并带有细腻流畅的过渡动画。

## 特性

- 受 Claude 界面启发的高颜值设计
- 柔和配色，适合长时间专注使用
- 平滑细腻的过渡动画

## 安装

1. 下载 `manifest.json` 和 `theme.css`
2. 在你的浏览器或应用中导入主题文件
