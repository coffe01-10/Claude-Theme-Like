# Obsidian Claude

一款温暖、优雅的 Obsidian 主题。主题名 **Amber**，琥珀色调搭配衬线字体，带来在暖灯下翻书的沉浸阅读体验。

A warm, elegant Obsidian theme named **Amber** — amber tones with serif typography, designed for immersive, distraction-free reading.

## 特性 / Features

- 暖琥珀色调，柔和护眼 / Warm amber palette, easy on the eyes
- 衬线字体排版，沉浸式阅读体验 / Serif typography for an immersive reading experience
- 细腻流畅的过渡动画 / Smooth, subtle animations

## 安装 / Installation

1. 下载 `manifest.json` 和 `theme.css` / Download `manifest.json` and `theme.css`
2. 将两个文件复制到 `<仓库>/.obsidian/themes/Amber/` / Copy both files to `<vault>/.obsidian/themes/Amber/`
3. 在 Obsidian 设置 → 外观 → 主题中启用「Amber」 / Go to Settings → Appearance → Themes and enable "Amber"
