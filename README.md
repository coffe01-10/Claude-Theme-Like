## Features

- Serif typography for an immersive reading experience
- Smooth, subtle animations

## Installation

1. Download `manifest.json` and `theme.css`
2. Copy both files to `<vault>/.obsidian/themes/Amber/`
3. Go to Settings → Appearance → Themes and enable "Amber"

# Obsidian Claude

一款温暖、优雅的 Obsidian 主题。主题名 **Amber**，琥珀色调搭配衬线字体，带来在暖灯下翻书的沉浸阅读体验。

## 预览

![截图1](images/屏幕截图%202026-05-03%20120337.png)

![截图2](images/屏幕截图%202026-05-03%20120433.png)

## 特性

- 暖琥珀色调，柔和护眼
- 衬线字体排版，沉浸式阅读体验
- 细腻流畅的过渡动画

## 安装

1. 下载 `manifest.json` 和 `theme.css`
2. 将两个文件复制到 `<仓库>/.obsidian/themes/Amber/`
3. 在 Obsidian 设置 → 外观 → 主题中启用「Amber」
